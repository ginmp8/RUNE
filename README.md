# RUNE

RUNE is a local .NET 10 document rendering workspace for Markdown, HTML, PDF input, and composite documents. The original 0.18.0 functional baseline includes a rendering API, worker, CLI, Streamlit Studio, NATS adapter, versioned contracts, and .NET, Python, and TypeScript SDKs.

## Source import status

This branch establishes the repository metadata for the RUNE 0.18.0 source import. The complete implementation is not yet present on this branch. Build and runtime qualification must not be inferred from this metadata-only commit.

The original 0.18.0 archive remains immutable. This import is not a new release, a release candidate, or an operational promotion.
