# Recovery RUNE 0.13.1

Use this procedure to repair artifacts generated by RUNE 0.13.0.

1. Deploy or run RUNE 0.13.1.
2. Re-submit the original composite request to regenerate the PDF and `structure-map.json`.
3. Re-submit the original artifact comparison request with `includePixelDiff=true`.
4. Verify the corrected composite visually page by page.
5. Replace only the affected generated artifacts; preserve prior outputs under their original release identity.

The source documents and comparison inputs do not require modification.
